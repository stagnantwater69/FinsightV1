# Finsight Mascot Scenario Library

A comprehensive map of every situation, state, and interaction across the web and mobile apps where the mascot should appear. Use this as the source list for illustration/animation production — each row is a distinct asset (or animation state) to design.

Legend for **Mascot Action/Pose** and **Expression** columns: describe the base pose; production can add idle/blink loops on top for motion.

## Additional mascot actions worth including (beyond the requested list)

These are common in modern fintech/AI/SaaS mascot libraries and round out the set:

- **Celebrating a first-time action** (first receipt scanned, first report generated) — distinct from generic success, marks a "first" specifically.
- **Comparing/weighing options** (holding two items on a balance scale) — useful for plan/tier comparison or AI recommendation choices.
- **Teaching/explaining a financial concept** (standing at a small whiteboard) — for in-app financial literacy tooltips, a differentiator for a fintech-for-small-business product.
- **Cheering from the sidelines** (pom-poms, mid-jump) — for referral/invite success or team member added.
- **Sleeping/idle state** for long inactivity (app backgrounded, dashboard untouched for weeks) — distinct from "no notifications."
- **Detective pose** (deerstalker hat, magnifying glass) — dedicated pose for fraud detection / anomaly investigation flows, separate from general AI analysis.
- **Umbrella/shelter pose** — for insurance, protection plans, or "your data is protected" trust moments.
- **Building blocks / construction** — for "feature coming soon" or in-progress capability messaging.
- **Handshake pose** — for integrations connected (bank sync, accounting software linkage), team invites accepted.
- **Reading glasses + document review** — dedicated pose for terms/consent screens, distinct from AI "thinking" pose.
- **Running late / hurrying** — for near-deadline reminders (tax deadlines, subscription renewal).
- **Recycling/composting pose** — for archive, trash, or "restore from trash" flows.
- **Binoculars/telescope** — for forecasting/projection features, distinct from retrospective insights.
- **Group photo / multiple mascots** — for team/multi-user account features, collaboration moments.
- **Bandaged/patched up** — for "issue resolved" post-incident states, distinct from generic success.
- **Question mark cloud overhead** — a lightweight "uncertain/thinking" variant usable across many micro-copy moments without a full illustration.

## Production notes

- **Consistency rule:** define one base rig (proportions, color palette, line weight) and treat every row above as a pose + prop swap on that rig, not a new character design — this keeps the library scalable and animatable.
- **Emotion range to lock first:** happy, thinking, worried, apologetic, celebrating, neutral/idle — these six cover roughly 70% of the rows above and should be built before the long tail of specific props.
- **Motion tiers:** static illustration (errors, empty states) vs. looping idle animation (loading, AI thinking) vs. one-shot celebration animation (success, milestones) — tag each row by tier during production planning.
- **Platform sizing:** mobile needs a compact/simplified silhouette variant for small empty-state cards; web can support more detailed full-scene illustrations.
